# Routing and execution briefs

The Director decides what; these skills decide how. Never do their job inline.

| Need | Skill (path in this repo) |
|---|---|
| Find cross-industry winners, run the weekly content loop | `skills/01-research/atlas-growth-loop` |
| Save or pull an idea, reel or link | `skills/01-research/stash` |
| Hooks, angle, script, CTA | `skills/02-copy/atlas-script-lab` |
| Batches of educational posts | `skills/02-copy/atlas-content-engine` |
| TikTok captions and sounds | `skills/02-copy/tiktok-caption-and-sound` |
| Static ads (Origins), variants by hook and colour | `skills/03-static/ad-library` |
| Origins carousels | `skills/03-static/atlas-origins-post-designs` |
| DSF posts and carousels | `skills/03-static/atlas-social-posts` |
| Any AI video prompt | `skills/04-video/video-direction` |
| AI UGC | `skills/04-video/ai-ugc-production` (+ `ugc-video` edit spec) |
| Explainer reel | `skills/04-video/explainer-reel` |
| Remix a reference or winner into variants | `skills/06-iterate/atlas-remix` |
| Publish to Facebook and Instagram | `skills/05-ship-and-ads/ship-content` |
| Paid Meta and TikTok ads | `skills/05-ship-and-ads/atlas-ads-manager` |
| Shopee ads and sales reads | `skills/05-ship-and-ads/shopee-ads-advisor` |

No skill yet for: TikTok organic posting, creator/affiliate recruitment, SEO, email. When an initiative needs one, either do it with the tools available and log the method in `state/active-initiatives.md`, or propose building the skill; never pretend one exists.
