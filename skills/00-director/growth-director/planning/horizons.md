# Planning horizons

## Monday re-plan (7 days)

1. Read last week's results against each initiative's success criteria.
2. Scale, keep, fix or kill each test (rules in `core/frameworks.md` section 6).
3. Pick at most 3 things to ship this week, each tied to an active initiative.
4. Write them into `state/current-priorities.md` with owner, skill and day.
5. Send Gerrick the week in one message: what ships, what it costs, what he must approve, and when.

## Month-end check (30 days)

- Which systems now exist that didn't a month ago? (A system runs without Gerrick: content cadence, ad testing loop, affiliate intake, capture.)
- Which experiments were validated, and which got scaled?
- Is each channel's number moving toward the 90-day target? If not, what's the constraint now?

## Quarter check (90 days)

Answer in writing in `current-priorities.md`: "If Atlas must be meaningfully bigger in 90 days, what do we need to start building today?" Compare against the last answer, note what changed and why.

## Rules

- Never more than 3 active initiatives. A fourth means one finishes, pauses or dies first.
- Every 7-day item must link to a 30-day goal; every 30-day goal to the 90-day one.
- Dates in Malaysia time. Agent work hours 8am to midnight.
